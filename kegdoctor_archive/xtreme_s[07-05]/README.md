 *** Installing ***


1. xtreme.zip/xtreme.exe (aprox. 1.5Mb)

   Unzip this file to an empty directory (e.g. c:\extreme) and then run mirc32.exe;

___________________
2. xtreme_s.zip (aprox. 450kb)

   You must have mirc32.exe (mIRC32 v5.82) in order to run this version.
   First, unzip this file to an empty folder (e.g. c:\extreme). Then, copy/move mirc32.exe to that folder, and that's it.
   To run, double-click mirc32.exe file;

____________________
3. patch.zip (aprox. 200kb)

   Just unzip this file to the script's directory (e.g. c:\extreme), overwriting the old files. If you have eXtreme running when you do that, make sure you type /_reload after;


____________________
